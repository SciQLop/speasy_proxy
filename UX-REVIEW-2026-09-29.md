# speasy-proxy UX review — 2026-09-29

Scope: home page, `/plot`, `/demo_3d`, and the HTTP API, as seen on the :devel
instance (v0.22.0) at 1440×900, plus the code. Two audiences:

- **Scientists**: open a page, look at an event, take the data into their analysis.
- **Engineers**: script against the API from any language, run and monitor the server.

Effort: S ≈ hours, M ≈ a day or two, L ≈ a week.

---

## What already works well

- The featured presets are real, documented events. They are the best entry point on the site.
- `/plot` is fast and dense: shared time axis, per-subplot toolbar, ISTP names and units, colour bars.
- Time handling is consistent: UTC everywhere, ISO fields, span chips, arrow-key pan.
- Share links carry the full view in the URL.
- API basics are sound: bad dates give 422, stop < start gives 400, epoch ints work, CORS is open, `Server-Timing` is sent, `format=cdf` is valid.

## Scientists

### S1 · The preset's story disappears once you open it · High · S
The home card explains the event ("CME shock at 17:05 UT, SYM-H down to −520 nT").
Click it, and `/plot` shows only the curves. The shaded intervals have no labels.
The "Events" panel is collapsed.
**Proposal:** keep the preset name and description as a one-line caption in the top bar
(or an expandable strip). Label shaded intervals on hover. Open the Events panel when a preset has events.

### S2 · No bridge from "I see it" to "I analyse it" · High · S
A scientist who finds something in `/plot` has to rebuild the request by hand in Python.
**Proposal:** a "Code" button next to Share. It shows ready-to-copy snippets for the current view:
- speasy: `spz.get_data("cda/THB_L2_MOM/thb_peim_velocity_gsm", "2008-02-26T04:30", "2008-02-26T05:20")` per product;
- a direct `get_data?...&format=cdf` URL (for IDL, Matlab, Julia, curl).

This is the single change that serves both audiences. All the needed state is already in `plotState`.

### S3 · Products are identified by raw paths · High · M
- The sidebar shows `cda/THB_L2_MOM/thb_peim_velocity_gsm` as the selected product.
- Top-level tree nodes are code names: `archive`, `uiowaephtool`, `cdpp3dview`, `csa`.
- The home header says "AMDA, CDAWeb, and SSCWeb", but the tree has seven providers.

**Proposal:**
- Display names and one-line descriptions for providers ("CSA — ESA Cluster Science Archive").
- A product info popover on the subplot badge: name, path, description, units, coverage, cadence, provider.
- Data acknowledgement: show the source (and DOI when the metadata has one) in that popover and in the PNG export.

### S4 · Finding a product among 77 000 · Med · M
Search is text-only over the tree. Most results have no data in the window you are looking at.
**Proposal:** a "has data in the current window" filter in the tree (coverage dates are already in
the inventory; `coverageOf` exists in `plot.js`). Later: filter by mission / instrument type.

### S5 · No way back after a zoom · Med · S
Views use `history.replaceState`, so the browser Back button leaves the page.
"Clear" wipes everything with no undo.
**Proposal:** `pushState` on committed views (debounced, after the refetch settles), so Back/Forward
walk the zoom history. Same mechanism makes Clear undoable.

### S6 · Time markers for event analysis · Med · M
Timing a shock across spacecraft means reading values off the tooltip.
**Proposal:** click to pin a vertical marker across all subplots. Two markers show Δt.
Markers go into the share URL and the Code snippet.

### S7 · Empty states waste the first impression · Med · S
- Bare `/plot`: a big dashed box saying "Drag a product here". No presets, no recent views.
- Bare `/demo_3d`: an Earth, empty date fields, "check satellites to plot their orbits".

**Proposal:** bare `/plot` shows the preset cards and the last few views (localStorage).
Bare `/demo_3d` preloads a default (e.g. MMS1 + THEMIS, last 7 days).

### S8 · Home page: half of it is ops data · Low · S
Below the presets sit nine status tiles (cache size, uptime, speasy version...).
A scientist wants to know one thing: "is AMDA down, or is it me?"
**Proposal:** replace the tiles with one row of provider health dots (from `/is_up`).
Move the detailed tiles to a small `/status` page linked from the footer.
Add thumbnails to preset cards (a static PNG per preset is enough).

### S9 · Data area at laptop size · Low · S
- The sidebar keeps 320 px (22 % of 1440 px) after a plot is loaded.
- With 4–5 subplots, ~100 px stay empty under the last one.

**Proposal:** auto-collapse the sidebar when a preset or share link opens. Let subplots fill the height.

## Engineers

Checked against the dev instance with curl; H1, H2 and H4 reproduced.

### E1 · Enum params are not validated · High · S
`Query(enum=[...])` on a `str` is only an OpenAPI hint (`api/v1/query_parameters.py`, `get_data.py:115-121`).
- `format=csv` → 200 `application/python-pickle` with a pickled `None`.
- `resample_strategy=foo&max_points=10` → 500 plain text (KeyError in `resample.py`).
- `coordinate_system=bogus` on `ssc/ace` → 200 `null`.

**Fix:** `Literal[...]` types. FastAPI then returns 422 and the schema stays right.

### E2 · `format=json` is not valid JSON · High · S
`json.dumps` writes bare `NaN` (fill values, `FILLVAL: [NaN]`). Strict parsers reject it.
Our own frontend regex-patches the text first (`static/js/api-client.js:10-14`).
**Fix:** NaN/Inf → `null` in `to_json` (`get_data.py:54-56`).

### E3 · JSON times are int64 nanoseconds · High · S–M
`1577836800000000000` is above 2^53; JS and any float64 parser round it silently.
**Fix:** `time_format=iso|epoch_ms` (default iso for new clients, keep ns behind the flag if anything depends on it).
Add a small top-level summary: `units`, `labels`, `time_range`.

### E4 · Unknown product → 502 · High · S
`amda/nope` → 502 "Unknown product". 502 blames upstream; retries and monitoring misread it.
**Fix:** check the path against the in-memory inventory first → 404. Keep 502 for real upstream failures.

### E5 · Four different error shapes · Med · S
`get_data` JSON `{error, detail}`, FastAPI 422 `{detail: [...]}`, `get_inventory` plain text, unhandled 500 plain text.
**Fix:** one exception handler, one JSON shape. Declare 400/404/502 in `responses=` so `/docs` shows them.

### E6 · Thin OpenAPI docs · Med · S
No descriptions on `path`, `start_time`, `format`, `pickle_proto`, `version`...
Nothing says which formats are language-neutral (json, cdf) vs Python-only (pickle, blosc).
`provider=all` works but is missing from the enum.

### E7 · No discovery without the web UI · Med · M
The only way to find a path is `/get_inventory` (60 MB for "all"), and the `provider/__spz_uid__` rule is undocumented.
**Fix:** `/products?q=&provider=` → flat `{path, name, start, stop, units}` list, and `/product?path=` for one product's metadata.
This is for API users only: `/plot` keeps downloading the whole tree (decided 2026-09-29).

### E8 · Caching and headers on `get_data` · Med · S
No `Cache-Control`, `ETag`, or `Content-Disposition` (a `.cdf` download has no filename).
`Server-Timing` is not in `Access-Control-Expose-Headers`, so browser JS cannot read it.

### E9 · Ops endpoints · Med · S
- `/get_cache_entries` pickles every cache key in one response, unauthenticated. Remove or paginate as JSON.
- No cheap liveness probe: `/is_up` probes an upstream provider. Add `/healthz`.
- `/get_server_status` advertises `speasyproxy.readthedocs.io`, which is a 404.
- `inventory_size` and `inventory_update_interval` are strings (`"2:00:00"`); use numbers (seconds).

### E10 · Docs · Low · S
README has no curl quickstart, no format table, and misses ~12 env vars from `config/__init__.py`.
`docs/` holds design plans only.

### E11 · HAPI facade · Low (big payoff) · L
A HAPI-compatible read endpoint makes the proxy usable out of the box from existing HAPI clients
(Python, IDL, Matlab, Julia, Autoplot). Worth considering after E7, since it needs the same flat catalogue.

## Suggested order

1. **API correctness batch** (≈ 1 day, all S): E1, E2, E4, E5, E6, dead docs link.
2. **Scientist quick wins** (S): S1 preset caption, S2 Code button, S5 Back = undo zoom, S7 empty states.
3. **Discovery** (M): E7 flat product search for API users. S3/S4 stay client-side, on the full tree `/plot` already has.
4. **Later**: S6 markers, E3 time format, E11 HAPI.
