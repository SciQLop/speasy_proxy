## What Was Done

### Bugs Fixed
- **Earth texture perf** (`demo3d.js`): replaced per-vertex color callback (64k verts/frame) with a pre-computed 360x180 color LUT sampled at load time
- **Spectrogram canvas crash** (`spectrogram.js`): capped canvas width at 4096px with column decimation
- **Share URL behind reverse proxy** (`plot.js`): `updateShareURL` now uses `BASE_URL` instead of `window.location.origin`
- **Wheel zoom padding** (`plot.js`): reduced from 5× to 1× the view (`AXIS_PAD_RATIO`)
- **fetchSpan not updated on heatmap merge** (`plot.js`): both merge paths now use `Math.max` to track widest span
- **selectProduct clobbering dates** (`plot.js`): only auto-fills when both inputs are empty
- **applyPendingUids loading overlay** (`demo3d.js`): now awaits `runWithConcurrency`
- **Magneto slider dropping trajectories** (`demo3d.js`): lightweight path now includes trajectory series
- **Magneto surface axis clipping** (`demo3d.js`): slider drag now also updates axis ranges
- **Reset view not resetting axes** (`demo3d.js`): now resets X/Y/Z ranges to fit data

### UX Improvements
- Default date window widened from 1 day to 7 days
- "Now" button added to range chips
- Per-product remove buttons in "Add to plot" dropdown
- Shift+Enter triggers "Add to plot"
- CSV export reports skipped spectrograms
- Orbit viewer: Clear + PNG export buttons, trajectory legend with loading spinners
- Duration buttons sync with manual start/stop edits
- Per-subplot loading indicator ("●" in title)
- Error boundary surfaces uncaught exceptions in status bar

### Performance
- Heatmap `valueRange` cached on load/merge, incremental on merge (not full re-scan)
- `trimCacheWindow` invalidates `valueRange` when trimming
- Data-only chart updates skip rebuilding grids/axes/titles (series-only `setOption`)
- `runWithConcurrency(3)` bounds parallel fetches in `applyPendingUids` and `replotAll`
- Slider drags update only magnetopause/bow shock surfaces (not full rebuild)
- Heatmap graphics folded into main option (one `setOption` instead of two)

### Cleanup
- `CHART_COLORS`/`REGION_COLORS` deduplicated into `common.js`
- `METADATA_KEYS` merged into shared `SKIP_KEYS`
- Dead imports removed

## How to Push

This repo has a personal-fork remote and an upstream remote. Per CLAUDE.md:
**Never push a feature/PR branch to upstream.** Push to the fork and open the PR cross-repo.

```bash
# Check remotes
git remote -v

# Push to fork (replace <fork-remote> with the actual name, e.g. `origin` or `jeandet`)
git push <fork-remote> main

# Open PR cross-repo (if fork is on GitHub)
gh pr create --repo <upstream-org>/speasy_proxy --head <fork-owner>:main --base main
```
